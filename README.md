# Personal Portfolio Website

This is my personal portfolio website, built to showcase my projects, skills, and experience. This project placed **first** and focuses on smooth design, interactivity, and user experience.

## Live Demo  
https://silentrequiem.github.io/Personal-Portfolio/

---

## Overview

This portfolio highlights my work as a developer through a clean layout and interactive design. The goal was to create a site that feels smooth and engaging while staying simple to navigate.

---

## Key Highlight

Designed and developed a **first-place award-winning** portfolio website using HTML, CSS, and JavaScript. The site includes custom animations, smooth transitions, a loading screen, and background music to enhance user experience.
